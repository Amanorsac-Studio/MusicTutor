# Quick Start

1. Run `npm install` and `npm run dev`.
2. Open `http://127.0.0.1:5173`.
3. Choose a scene and edit the lesson title in Studio.
4. Play the on-screen keyboard or use the `A–;` keyboard row.
5. In Devices, choose **Connect devices** to grant camera/microphone access.
6. Use Mixer to set balance and voice ducking.
7. Return to Studio and choose **Start recording**.

The current recording control exercises the workflow and timer; it does not yet encode a video file.
