# Decisions

- The primary studio render is the structural reference.
- Devices, Mixer, Library, and Settings remain separate.
- The first deliverable is a tested interactive vertical slice because the repository began without source, a build system, JUCE, FFmpeg, or hardware fixtures.
- Browser device permission is real; native device behavior is not simulated.
- Native V1 targets Windows/WASAPI/ASIO/VST3 first unless macOS becomes a launch requirement.
