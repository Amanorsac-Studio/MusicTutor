MusicTutor 0.1.0
Amanorsac Studio - amanorsac.studio

WHAT THIS IS
A lesson studio for music teachers: record and stream tutorials, and learn
songs by ear with chords, notes and separated instruments.

INSTALLING
Windows   Run MusicTutor-0.1.0-Windows.exe and follow the installer.
macOS     Open MusicTutor-0.1.0-macOS.dmg and drag MusicTutor to Applications.

WHAT GETS INSTALLED
Standalone   C:\Program Files\MusicTutor\   (the installer lets you change this)
             /Applications/MusicTutor.app

YOUR LESSONS AND SETTINGS
Windows   Documents\Amanorsac Studio\MusicTutor\
macOS     ~/Documents/Amanorsac Studio/MusicTutor/
Uninstalling does not delete these.

NO ACTIVATION
There is no key and no account in this version.

WHAT USES THE INTERNET
Only what you start yourself: going live to a streaming service, the YouTube
browser in the Learn tab, and a one-time download of the instrument
separation model the first time you use it. Your audio never leaves your
computer.

UNINSTALLING
Windows   Settings > Apps > MusicTutor > Uninstall
macOS     Drag MusicTutor from Applications to the Bin.
